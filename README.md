Calculator IN C

A lightweight, blazing fast and user-friendly command-line calculator built entirely in standard C.

✨ Features: 

Fast & Lightweight:  Zero external dependencies, pure standard C (`C99`/`C11`).
Basic arithmetic: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`).
Advanced operations: Modulo (`%`), Exponentiation (`^`), Square Root (`√`).
Error Handling:Robust checks for division by zero,invalid operator input and domain errors.
Interactive CLI: Clean terminal interface with an continuous evaluation loop.

Make sure you have a C compiler installed on your system (such as gcc or clang).
Linux / macOS: GCC or Clang (usually pre-installed or via package manager)
Windows: MinGW, GCC, or MSVC
Compilation & Execution
Clone the repository:

Bash
git clone [https://github.com/your-username/CALCULATOR-IN-C.git](https://github.com/your-username/CALCULATOR-IN-C.git)
cd CALCULATOR-IN-C
Compile the program:

Bash
gcc -o calculator main.c -lm
(Note: The -lm flag links the math library required for advanced operations like pow or sqrt)

Run the executable:

Bash
./calculator
